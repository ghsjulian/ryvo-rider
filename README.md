### 🚓 Ryvo Taxi Booking

**RYVO TAXI BOOKING** - is a modern full-stack taxi booking platform that enables users, nurses & doctors to book taxi immediately, nurses and riders to connect through authentication.

The platform provides secure authentication, payment, profile management, social interaction, real-time location, and an intuitive responsive interface designed for both desktop and mobile devices.

Built using modern web technologies, the application follows scalable architecture and production-ready development practices suitable for commercial deployment.
